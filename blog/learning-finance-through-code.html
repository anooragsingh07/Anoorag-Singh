Learning Finance Through Code — Student Finance Tracker

April 10, 2024 · 6 min read

Tracking spending is easier when transactions and category totals are visible together. This project turns that idea into a small budgeting tool for students.

Managing personal expenses can be difficult when purchases are scattered across memory or notes. I built the Student Finance Tracker as a student-focused way to record transactions and see how spending adds up.

From a transaction list to a picture

The tracker supports adding and deleting transactions, filtering entries, and grouping activity by category. A dashboard presents category breakdowns and responsive charts, making it easier to spot how the pieces relate to a budget.

Chart.js provides the visualizations, while the rest of the interface uses HTML, CSS, and JavaScript. Combining a transaction list with a chart was a useful exercise in keeping data and its visual summary in sync.

Keeping data available offline

The project stores information in localStorage, so the data can remain available in the browser between visits without a backend. That choice keeps the app lightweight and makes it usable offline, while keeping the storage model simple for a learning project.

Working with browser storage also made me think carefully about the app’s state: a change to a transaction needs to update both the list and the chart, and category filters should give a clear view of the matching entries.

What I practiced

Building the tracker gave me practice with DOM manipulation, event handling, data filtering, and Chart.js. It also reinforced a useful product principle: a dashboard should make the next useful question easier to answer, rather than adding charts for their own sake.
