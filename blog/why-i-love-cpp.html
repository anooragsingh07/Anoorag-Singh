Why I Love Coding in C++

May 28, 2024 · 5 min read

C++ introduced me to the logic behind programming and gave me a close view of how software works with memory and the machine.

C++ was the language that made programming feel tangible to me. I could write a solution, follow how data moved through it, and connect the code to the computer science ideas I was learning. That combination made it a language I kept returning to.

Learning to think in steps

Solving problems in C++ encouraged me to describe a task precisely before reaching for code. Data structures and algorithms made that habit especially useful: choosing a representation, considering edge cases, and explaining why an approach works all matter as much as getting a program to compile.

The language also gave me room to learn object-oriented programming and to understand how lower-level operations fit into a larger program. Working with memory and values directly made performance and ownership feel less abstract.

From exercises to a simulator

I used C++ for problem solving and for projects such as CPU-SchedSim. Implementing scheduling policies meant turning each rule into a repeatable process: track arrivals, decide which process runs next, handle a time slice or preemption, then calculate the results.

That project connected the language to operating-systems concepts. Instead of only reading about a scheduler, I could build one and inspect how a different workload or policy changed the outcome.

A useful foundation

C++ can be demanding because it gives programmers many details to manage. I have found those details useful for learning. They invite questions about what a program is doing, why a data structure behaves a certain way, and how a design can stay understandable as it grows.

I still enjoy using C++ because the language lets me move between problem-solving practice and systems-oriented projects. It helped build the foundation I use when learning other tools and technologies.

Resources I used

My learning included Codecademy, The Cherno, and GeeksforGeeks. Building small programs and revisiting the fundamentals helped turn new syntax into concepts I could apply.
